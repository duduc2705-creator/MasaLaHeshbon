# מסע לחשבון

פרויקט משחק לימודי לתרגול חשבון לילדים.

גרסת העבודה הסופית האחרונה שאותרה בפרויקט: **v1.2.0 GOLD**.

## עיקרי המשחק
- 1–3 שחקנים
- לוחות חשבון מעוצבים
- שאלות ותרגילים לאחר נחיתה
- הזזת חייל ידנית
- קובייה, תורות ובונוסים
- מסך ניצחון וסיום
- תמיכה במסך מגע / לוח חכם
- מוזיקה, אפקטים והשתקה

ה־repository ישמש מעכשיו לניהול גרסאות, תיקונים ו־GOLD releases של מסע לחשבון.
